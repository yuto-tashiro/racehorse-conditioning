# Project Principles
This website is an evidence-based educational resource for racehorse conditioning and equine sports medicine.
Never invent citations, PMID, DOI, authors, journals, results or sample sizes. Verify references before publication. Distinguish equine clinical, experimental, human, mechanistic evidence and expert opinion. Physiological effects do not establish clinical effectiveness.
Every medical or rehabilitation article must contain Evidence Summary, Limitations, References and Last Evidence Review. Unverified claims must be marked REFERENCE_REQUIRED and must not imply verified medical guidance.
Use TypeScript and strict schema validation. Keep scientific content in /src/content and reusable evidence logic in components and schemas. Never hard-code evidence ratings into visual components.
Run npm run typecheck, npm run test, npm run build before completing major changes.
